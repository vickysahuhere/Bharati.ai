Bhai suno, college aur school life me boring institutional chatbots bahut dekh liye. Sab robot ki tarah formal English me baat karte hain jaise Dubey sir ka viva chal raha ho. 

Toh humne socha — **Thoda masti aur dhasu jugaad ho jaye!**

**Budbak.ai** is an ultra-animated, cartoon neo-brutalist AI banter bot inspired by the legendary antics of **Badri** and **Budhdeb** from *Bandbudh aur Budbak*. It answers your college questions, BCA datesheets, and syllabi — par ekdum backbencher twist, filmy dialogues, aur samosa philosophy ke sath!

## 🛠️ The Tech Under the Hood (For Dubey Sir's Technical Viva)

Even though it looks like Saturday morning cartoons, the engineering underneath is enterprise-grade:

- **Frontend:** React 18, Vite, TailwindCSS (Cartoon Neo-Brutalism design system with 3.5px black borders, halftone dot patterns, custom SVG avatars).
- **Audio Synth:** Pure JavaScript Web Audio API oscillator nodes with custom gain envelopes.
- **Backend API:** FastAPI (Python 3.12) with rate-limiting & anti-bot traps.
- **RAG & Vector Database:** PostgreSQL 16 + `pgvector` storing 384-dimensional dense semantic chunks.
- **Embedding Engine:** `BAAI/bge-small-en-v1.5` running locally on CPU via `FastEmbed`.
- **LLM Pipeline:** Groq Llama 3.3 70B with an intelligent offline cartoon fallback engine that synthesizes retrieved evidence seamlessly.

## 🏃 Running Locally (Host Your Own Bunk Party)

### Prerequisites:
- Docker & Docker Compose installed
- A sense of humor (mandatory)

### 1. Clone the Katta:
```bash
git clone https://github.com/vickysahuhere/Bharati.ai.git
cd Bharati.ai/camp-ai
```

### 2. Check the Environment:
```bash
cd deploy
# Copy or edit .env if needed
# Default setup runs out of the box with PgVector & local FastEmbed!
```

### 3. Fire up Docker:
```bash
docker compose -p college-a --env-file .env up -d --build
```

### 4. Open in Browser:
Visit **[http://localhost:8000](http://localhost:8000)** and let the chaos begin!
